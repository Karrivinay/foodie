# 🍔 Foodie – Zomato-Inspired Food Delivery Frontend

Foodie is a modern, responsive food delivery website frontend inspired by popular food discovery and delivery platforms like Zomato.

The project is built using **HTML, CSS, and JavaScript** and focuses on creating a clean, interactive, and responsive user interface.

---

## 🚀 Features

- 🏠 Modern food delivery homepage
- 🔍 Restaurant and food search
- 📍 Location selection UI
- 🍕 Popular cuisine categories
- 🍔 Restaurant listing cards
- ⭐ Restaurant ratings
- 🏷️ Discount/offer badges
- ❤️ Favourite restaurant button
- 📱 Responsive design for mobile, tablet, and desktop
- 🖼️ Food and restaurant imagery
- 📚 Restaurant collections section
- 📲 Mobile app promotion section
- 🔐 Login and Sign Up UI
- ⚡ Interactive search using JavaScript
